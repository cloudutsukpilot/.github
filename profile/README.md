### How this org works

Every project here gets a **playbook** on the blog: vision, requirements, architecture, security, CI/CD, operations and lessons learned, one post per area. Every **lab** comes with a runnable repo, real dashboard screenshots and experiments you can repeat.

Most repos are private while they're being built, so the links below go to their write-ups.

### Projects

| Project | What it is | Status |
| --- | --- | --- |
| [Cloudutsuk Platform](https://cloudutsuk.com/tags/cloudutsuk-platform/) | Self-hosted control plane on an NVIDIA DGX Spark: one SSO portal for every lab, cloud resource and its cost, with OpenTelemetry, local CI/CD and GitOps, a local-LLM RAG chatbot and an alert-driven SRE agent. | 🚧 In progress |
| [Platform Wardens](https://cloudutsuk.com/tags/platform-wardens/) | Multi-agent framework for operations: Pydantic AI agents on Temporal that observe, diagnose and recommend for DevOps, SRE and DBA, with autonomy enforced in code. | 🚧 In progress |
| [RAG on Cloud](https://cloudutsuk.com/tags/rag-on-cloud/) | Retrieval-augmented generation on Azure, AWS and GCP from the same code, scored on one golden question set. | 🚧 In progress |
| [Job Hunter Agent](https://cloudutsuk.com/tags/job-hunter-agent/) | Finds jobs, scores them against a resume and drafts tailored applications that wait for approval. | ✅ Live |
| [Productivity Dashboard](https://cloudutsuk.com/tags/productivity-dashboard/) | GitHub and Jira activity turned into daily, weekly and monthly summaries with Azure OpenAI. | ✅ Live |
| [State of DevOps](https://cloudutsuk.com/tags/state-of-devops/) | Daily scorecard of DevOps best-practice adoption across GitHub organizations. | ✅ Live |
| [Y-IaC](https://cloudutsuk.com/tags/y-iac/) | Shared Terraform/Terragrunt modules, a YAML-driven CLI and reusable GitHub Actions for policy-gated plans. | ✅ Live |
